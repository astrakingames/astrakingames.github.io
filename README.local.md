# Astrakin Games Studio website

Static GitHub Pages site. To preview locally, run `python3 -m http.server 8000` from the repository root and visit http://localhost:8000/. The directory index files support the intended clean URLs.

The privacy page is a placeholder, not a policy. Before publishing or submitting it to a store, audit the actual game and SDK configuration, confirm the developer's public contact, complete and review the policy, and set its effective date. Verify all public URLs after deployment.
